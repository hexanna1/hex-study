How Rex+ works

Add one or more stones of your color, then end the turn. Making your own Hex connection loses.

The displayed winner assumes you end the turn after the latest stone. Each cell shows who wins if you add that stone and end the turn. Adding further stones usually works against that color, but there are rare exceptions; see an example.

For more details, see the solver code.
